fxbot v0.7.0 is out!

https://fxbot.sh/docs/reference/changelog/

Before upgrading: the update adds a few columns to your database, for first-run setup, your bots' looks, and the order you put them in. Your bots keep their shapes, colors, and order. Then update your plugins from Plugins: each of fxbot's shows Update available once.

Changes:

- New Plugin: Pages => Bots write reports, guides, and plans to read outside the chat, in Markdown or HTML, with every version kept
- Pages remember: tick a task list, an HTML page saves what you do on it, a routine can send it new numbers, and a page can draft a message to its bot
- Bots have a new look: big dark eyes, soft colors, and 32 shapes, with a feeling and things to wear
- Bots show what they're doing: working, waiting on you, finished, or asleep
- A new bot screen, with tabs for each part of the look, and Surprise me
- First-run setup walks a new install through plugins, a provider and a model, and a first bot
- Essentials: what most people want from fxbot, at the top of Browse
- Right-click a bot in the sidebar, or hold it on a phone, to edit it, pin it, make it the default, or delete it
- Drag bots and rooms in the sidebar into your own order
- The default bot wears a star in the sidebar
- Bots pass on your own words when one asks another for help, so the work stays yours (with Messages)
- Auto asks about what's risky, not everyday work like editing files or starting a service (with Permissions)
- fxbot knows which plugins can run on it, and a plugin a release breaks stops as Unsupported instead of breaking a bot
- Settings warns before an update about plugins that wouldn't run on it
- Bug fix: the message box is whole when a chat opens (with Messages)
- UX Fix: a bot's edit page keeps Save in view
- UX Fix: on a phone, the new bot screen keeps the bot and its tabs in view as you scroll
